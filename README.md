## 学习路线

- [ ] **阶段 1：LLM 基础**
  - [ ] 什么是大语言模型、token、上下文窗口

  - [ ] Prompt 编写基础：system prompt、多轮对话
- [ ] **阶段 2：工具调用（Tool Use）**
  - [ ] 让模型调用你定义的函数（[examples/02-tool-use](examples/02-tool-use/)）
  - [ ] 结构化输出（JSON）
- [ ] **阶段 3：Agent 循环**
  - [ ] Agent = 模型 + 工具 + 循环（[examples/03-simple-agent-loop](examples/03-simple-agent-loop/)）
  - [ ] 错误处理与停止条件
- [ ] **阶段 4：进阶主题**
  - [ ] RAG（检索增强生成）
  - [ ] MCP（Model Context Protocol）
  - [ ] 记忆与上下文管理
  - [ ] 多 Agent 协作
  - [ ] 评估（Evals）
- [ ] **阶段 5：做一个自己的项目**（放在 [projects/](projects/)）
